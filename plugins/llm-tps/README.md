# LLM TPS

在插件中心启用 `llm-tps`，再把它绑定到需要统计的路由。只有路由绑定会采集样本；全局、服务或上游绑定会被明确拒绝。单独启用插件不会自动采集全部路由。管理仪表板提供总览、端点、模型三张独立卡片，共享 1、12、24 小时时间窗口及每分钟刷新。

TPS 只统计输出 Token。单次速率为 `outputTokens / generationDurationMs × 1000`，耗时单位为毫秒。汇总与分组速率为 `ΣoutputTokens / ΣgenerationDurationMs × 1000`，按生成耗时加权；它衡量生成速度，不表示并发请求的整体吞吐量。无样本时速率为空，输出为零的有效样本速率为零。

总览卡片右侧展示所选范围内的生成速度趋势。1、12、24 小时范围分别按 1、30、60 分钟分桶，以样本完成时间归桶，每桶采用同一加权公式。没有样本的时间点在趋势图中按零绘制，保留完整时间轴；显示补零不参与 TPS 汇总或样本数计算。

端点按「路由 + 实际上游 host」分组，模型按「路由 + 模型」分组，不跨路由合并。同一路由的多个端点实际请求同一 host 时，采用同一耗时加权公式合并；同一端点实际请求不同 host 时分别统计。host 来自最终出站 URL，包含非默认端口，支持 IPv6，不由配置 UUID 或当前端点地址推断。模型身份直接使用 `token-metering` 的结果，与 Token 统计口径一致；不从路由名称或模型别名推断。缺少模型身份的样本继续参与总览及端点统计，不参与模型分组。升级前的明细没有模型信息，不回填。

两张明细卡以降序排行展示实际上游 host 或模型名、路由路径和速率，橙色横向柱形辅助比较，单位在标题栏中显示一次。每张卡片独立以当前最高 TPS 为满长，其余柱长按「当前 TPS ÷ 该卡片最高 TPS」计算；所有值为零时柱长均为零。数值仍展示实际 TPS，柱长表示卡片内部的相对速度，不表示流量占比；不截取前几名，全部分组可滚动查看，滚动到边界后可继续滚动页面。

样本来自 `token-metering` 的可观测流式生成，包括 HTTP 流和 WebSocket 生成。宿主仅为完整成功的流提供正生成耗时，TPS 以此作为独立成功资格，不依赖会计结算的 `outcome`。只纳入观察完整、输出 Token 已知且生成耗时为正的结果；非流式、失败、取消或无法计时的生成，以及部分或未知输出用量不参与统计。输入 Token 未知不会排除有效的输出样本。官方用量优先，官方输出用量缺失时使用计量服务已有的估算，界面显示估算样本数量。

样本保存在观察数据库中，按 attempt ID 去重，保留 31 天。每次写入最多清理 500 条过期样本。停用或解除绑定会停止采集，保留的历史数据仍可查询。统计写入通过最多 256 个待处理样本的异步队列执行，销毁会退订并排空已接受的写入；队列满、观察失败或写入失败会记录统计不完整状态，不阻断代理转发。存储不可用时查询明确失败，不以空数据代替错误。

明细保留配置端点身份；身份为 URL 时存储 SHA-256 前 16 位组成的 `endpoint-…` 标识。聚合接口直接返回采集到的 `upstreamHost`，界面不反查配置，也不显示 UUID 占位名称。host 不包含 URL 凭据、路径、查询参数或片段。升级前没有 host 的样本无法可靠回填，继续参与总览、模型和趋势统计，不进入端点 host 排行；缺少 host 的新样本遵循相同规则。

控制面 `GET /stats?range=1h|12h|24h` 默认使用 `24h`，窗口包含起止时间，一次返回总览、端点、模型和总览趋势。宿主根据声明的 `logs.read` 权限授权访问；重复或无效参数返回 400，存储错误返回 5xx。
