# Token 统计

在插件管理中激活 Token 统计后，它自动作为全局插件观察所有代理路由，无需在全局配置、route、service 或 upstream 中手动添加绑定。停用插件即可停止采集。已有的绑定不会产生多个实例或重复统计。

插件根据实际发往上游的请求地址与协议结构，识别 OpenAI Chat Completions / Completions / Responses、Anthropic Messages 和 Gemini GenerateContent / StreamGenerateContent。支持自定义代理域名与模型名称；自定义地址上的共享聊天结构先识别为 LLM 调用，再根据响应确定协议。无法从请求判断时，也可以通过 JSON 或 SSE 的生成响应结构识别。

对于没有提供 `Content-Type` 的流式上游，采集层会根据实际请求的 SSE 标记识别响应，仍然在协议转换前读取官方用量。

普通请求不会写入 Token 统计。单独的 `input`、`prompt`、`messages`、`usage` 字段或 SSE 类型不足以识别 LLM；请求需要符合生成协议的结构，例如模型加聊天消息或 Responses 输入。共享字段存在歧义时不猜测具体协议。

每次实际发出的 LLM 上游尝试单独记录，包括重试和失败；未获得可靠用量的失败尝试记为未知，不记为零。成功调用优先采用上游官方用量，缺失时按已有规则估算。采集从激活后的新请求开始，历史访问日志不会自动补算。

全局行为由 manifest 的 `runtimeScope: "global"` 声明。未声明该字段的其它插件继续使用现有的作用域绑定机制。

全局插件仅在插件管理中激活和配置，不出现在 route、service、upstream 的添加插件列表。旧配置中已有的 Token 统计绑定继续被忽略，不会重复统计。

在插件管理的 Token 统计设置页可以手动刷新价格，或开启自动刷新。默认每 60 分钟更新一次，下载超时为 15 秒；可设置 1–1440 分钟的间隔与 5–60 秒的超时。关闭自动刷新仍可手动更新。

价格目录固定来自 `https://models.dev/api.json`，由管理进程统一下载，并保存到插件的共享持久化存储；worker 只读取缓存。支持 OpenAI、Anthropic、Google 和 xAI 的明确模型价格。重启保留配置与有效价格；失败保留旧缓存，自动刷新开启时按 1、2、4、8、15 分钟退避重试（不超过设置的刷新间隔）。配置页显示下载状态、成功时间、下次刷新时间和失败原因，仪表板仅展示用量和费用。

价格更新只影响后续请求，历史未知金额不会按新价格自动补算。无匹配价格的模型费用仍显示未知，不能当作零费用；目录估算也不等于提供商的实际账单。

仪表板卡片高度由容器控制，Token 卡片默认 320px，最小 300px，以保留切换按钮、统计栏和空状态的可用空间。标题、维度切换与三项汇总统计固定，只有模型列表独立滚动。时间图填充剩余高度，不滚动；每张时间图共用一个 Tooltip，切换柱子时复用提示框并更新内容和定位锚点，不为各柱子创建独立实例。提示使用短时淡入淡出和位置过渡，并遵循系统的减少动态效果设置。时段详情在柱子旁展示并自动避让屏幕边缘；鼠标离开或焦点移开后关闭，触屏点击查看，再次点击或点击外部关闭，不挤压图形。宿主可在卡片容器设置 CSS 变量 `--bungee-widget-height` 覆盖高度，后续高度配置应接入此处，不必由插件自行计算卡片高度。
