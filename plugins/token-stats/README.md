# Token 统计

## 激活与采集

在插件管理中激活 Token 统计后，它自动作为全局插件观察所有代理路由。插件声明 `runtimeScope: "global"`，在插件管理中激活和配置，不出现在 route、service、upstream 的添加插件列表；这些作用域中的绑定会被忽略，不会产生多个实例或重复统计。停用插件即可停止采集。

插件根据实际发往上游的请求地址与协议结构，识别 OpenAI Chat Completions / Completions / Responses、Anthropic Messages 和 Gemini GenerateContent / StreamGenerateContent。支持自定义代理域名与模型名称；自定义地址上的共享聊天结构先识别为 LLM 调用，再根据响应确定协议。无法从请求判断时，也可以通过 JSON 或 SSE 的生成响应结构识别。

对于没有提供 `Content-Type` 的流式上游，采集层会根据实际请求的 SSE 标记识别响应，仍然在协议转换前读取官方用量。

普通请求不会写入 Token 统计。单独的 `input`、`prompt`、`messages`、`usage` 字段或 SSE 类型不足以识别 LLM；请求需要符合生成协议的结构，例如模型加聊天消息或 Responses 输入。共享字段存在歧义时不猜测具体协议。

每次实际发出的 LLM 上游尝试单独记录，包括重试和失败；未获得可靠用量的失败尝试记为未知，不记为零。成功调用优先采用上游官方用量，缺失时按已有规则估算。采集从激活后的新请求开始，历史访问日志不会自动补算。

## 定价与模型映射

价格目录由 [models-dev](../models-dev/README.md) 提供，Token 统计通过公开服务 `models-dev.catalog.v1` 读取本进程的只读目录视图。目录刷新设置与状态在 models-dev 设置页，刷新失败保留最后有效目录，无目录时费用显示未知而不是零。

设置页的「模型价格映射」支持最多 100 条客户端别名：填写统计中实际出现的模型名称，再选择价格提供商和可搜索的价格表模型。例如可将 `deepseek-ai/deepseek-v4-flash` 映射到 `deepseek` 的 `deepseek-v4-flash`，将 `GLM-5.3-flash` 映射到选定提供商的 `glm-5.3-flash`。以当前已下载目录为准，不自动创建或猜测价格。别名区分大小写、不能重复，不支持通配符或链式映射；目标必须是目录中的有效价格模型。映射优先于直接匹配与上游主机提示，不改写代理请求或统计模型名。

映射独立持久化，保存、修改、删除后各 worker 在后续定价时读取，无需刷新价格。刷新不会覆盖映射；若目标模型从目录消失，该别名费用保持未知，不回退到其他模型。可原样保留失效映射并修改其他行，新增或修改的映射必须选择有效目标。映射读取或解析失败时不回退到默认价格，费用显示未知；管理页加载失败时禁止保存，避免覆盖原配置。未配置映射时，显式 pricing provider（目录 provider id）优先；否则按真实请求主机与完整目录 `provider.api` 规范化（host + 路径段）匹配，多个来源命中即歧义未知；带目录提供商前缀的模型直接匹配；其余模型仅在目录中存在唯一精确匹配时计价，同名多提供商必须显式指定映射。统计与金额预算复用同一定价服务。

价格更新只影响后续请求，历史未知金额不会按新价格自动补算。无匹配价格的模型费用仍显示未知，不能当作零费用；目录估算也不等于提供商的实际账单。

## 统计展示

仪表板提供两张独立卡片：Token 概览显示输入、输出和费用预估；时间趋势卡展示按模型堆叠的时间图。两张卡片同步使用仪表板的 1／12／24 小时范围。已保存的组合卡片布局在加载时转换为趋势卡片，并在布局容量允许时补入概览卡片；已移除的 Token 卡片不会自动恢复。

从顶部「Token统计」、插件管理中的「页面」，或时间卡标题栏的「查看模型统计」进入独立统计页。页面展示输入、输出、Token、费用预估、Token 趋势和完整模型排行，支持搜索模型及按 Token、费用排序。排序只改变模型顺序，各行始终展示 Token 构成。模型行的缓存读取、缓存写入数值后显示占输入 Token 的百分比，输入为零或未知时显示「—」。长数字缩写为 K/M/B/T，最多保留两位小数，悬浮显示完整值。价格配置在插件设置页。

独立统计页默认查看「本日」，提供「本日／本周／本月／最近1天／最近7天／最近30天」。最近范围从当前时刻向前回溯连续的 24 小时、7×24 小时或 30×24 小时，分别按 1 小时、24 小时、24 小时分桶，共 24／7／30 个时段；提示显示每个区间的起止时间。本日从浏览器所在时区的今天零点开始，展示完整自然日的小时分桶（通常 24 个，夏令时切换日为 23／25 个）。本周从浏览器所在时区的周一零点开始，本月从当月第一天零点开始，分别展示完整的 7 天和当月实际天数，按本地自然日分桶。自然周期的未来时段留空，统计查询只计入当前时刻之前的数据，提示使用完整时段的起止边界。

Token 明细保留 31 天，写入时每次最多清理 500 条过期明细。已清理的数据不能恢复。仪表板的 1／12／24 小时范围分别使用 5 分钟／1 小时／2 小时分桶。缓存读取和写入是输入 Token 的细分，构成图不会重复相加。未知 Token 和费用显示「—」，不会当作零。

时间图随容器宽度自适应，按日期排列时段；7 天及本周视图展示逐日刻度，较长范围按可用宽度抽取刻度。支持悬浮和触屏查看，键盘聚焦后可用左右箭头、Home／End 查看时段，Escape 关闭提示。相同范围和维度的组件共享查询结果，每分钟刷新；离开页面或切换范围会取消过时请求。


统计页支持 API Key 筛选，模型排行、概览与时间图使用同一筛选。全部 Key 不加查询参数；`?keyId=<真实 Key ID>` 只查看该 Key；`?keyId=__unattributed__` 查看匿名及未记录归属的历史行。页面链接中的已删除或未知 Key ID 会继续筛选该 ID，不会自动改成全部。归属只来自 worker 的可信服务端身份，不读取客户端声称的 Key ID；没有可信归属的记录为 NULL。

## 定价服务

Token 统计向同一 worker 进程发布 `token-stats.pricing.v1`（契约版本 1），供金额预算复用价格目录与结算结果。`canPrice` 用零 Token 检查合法单价；`price` 返回 `costUsd` 和安全非负整数 `costNanoUsd`，1 USD = 10^9 nanoUSD，费用按最近整数四舍五入。未知价格、缺少必要用量及金额溢出均返回两个 NULL。同一尝试、结算版本和定价输入共享一个有界缓存结果，统计异步队列使用同一金额；价格更新不会让同一次结算的统计与预算金额分歧。

## 客户端模型搜索 API

`GET /models?search=&page=&pageSize=` 返回保留期内真实 attempt/客户端模型名去重列表（保留原始大小写），不受仪表板当前时间范围或 Top N 限制，支持关键字搜索与分页、有界响应。存储读取失败返回 5xx 错误而不是空成功；不会插入任何虚假记录。

## 设置页的目录加载

首屏读取状态、映射和 provider 摘要，不加载全部模型。模型选择器打开后按 provider 和关键词请求每页 50 项；非空搜索防抖 250 ms。关闭、换 provider 或销毁取消请求，迟到响应不能覆盖新查询，目录版本变化时重新查询已打开的选择器。

部分分页不能证明既有映射无效，因此保留确认值的显示，保存仍由服务端校验。客户端模型来自真实保留期统计，保持大小写并允许明确自由输入；选择器不能制造统计数据。模型目录方法及服务边界见 [models-dev](../models-dev/README.md)。
